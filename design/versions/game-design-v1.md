## 1. はじめに  
- **目的**：zoo‑catcher のゲーム設計書を完成させ、開発チーム全員が同一理解で作業できるようにする。  
- **対象読者**：ゲームプログラマ、アートディレクター、サウンドデザイナー、テスター、プロダクトマネージャー。  
- **前提知識**：Issue 006 の要件、Unity（または対象エンジン）の基本操作、Web API の利用経験。  

## 2. ゲーム概要  
- **ジャンル**：タイムアタック型アクション／シミュレーション。  
- **プレイ時間**：5 秒 → 60 秒（ゲーム開始時に設定）。  
- **主なゲームプレイ**：クリック（タッチ）で動物を捕獲し、逃走コンボで倍率を上げる。  
- **レア動物**：1 % の出現確率。  
- **スケーリング**：ゲーム進行に伴い速度が上昇。  
- **ハイスコア**：LocalStorage に保存し、リロード時に復元。  

## 3. ゲームルール詳細  
1. **タイムアタック**  
   - ゲーム開始時に 5 秒のタイムリミットを設定。  
   - 60 秒に拡張するオプションを実装し、プレイヤーが選択可能に。  
2. **クリック捕獲**  
   - 画面上にランダムに動物が出現。  
   - タップ／クリックで捕獲。  
   - 捕獲成功時にスコアが加算。  
3. **逃走コンボ倍率**  
   - 捕獲後、一定時間内に次の動物を捕獲するとコンボが増加。  
   - コンボ倍率は 1.0 → 2.0 → 3.0 … と上昇。  
   - コンボが切れたら倍率は 1.0 にリセット。  
4. **レア動物出現確率**  
   - 通常動物 99 %、レア動物 1 %。  
   - レア動物はスコア倍率が 2.0 倍になる。  
5. **スケーリング速度増加**  
   - タイムが経過するごとに動物の出現速度が 5 % ずつ上昇。  
   - 速度上昇は 10 秒ごとに適用。  
6. **ハイスコア保存**  
   - LocalStorage に `highScore` キーでスコアを保存。  
   - ゲーム開始時に読み込み、画面上に表示。  

## 4. アセット・データ設計  
- **動物データ**  
  - `id`, `name`, `image`, `speed`, `isRare`, `scoreValue` のプロパティを持つ JSON。  
- **UI アセット**  
  - タイマー、スコア表示、コンボ表示、レア動物アイコン。  
- **音声**  
  - 捕獲音、逃走音、レア動物音。  

## 5. 実装注意点  
- **パフォーマンス**  
  - 60 秒で多数のオブジェクトが生成されるため、オブジェクトプールを使用。  
- **タッチ対応**  
  - `Input.GetMouseButtonDown` と `Input.touchCount` を併用し、PC とモバイル両方で動作。  
- **LocalStorage**  
  - `window.localStorage.setItem` / `getItem` を使用し、JSON 文字列で保存。  
- **スケーリング**  
  - `Time.deltaTime` を利用し、フレームレートに依存しない速度調整。  

## 6. UI フロー  
1. **タイトル画面**  
   - 「スタート」ボタン、タイム設定（5 秒/60 秒）セレクタ。  
2. **ゲームプレイ画面**  
   - タイマー、スコア、コンボ表示。  
   - 動物がランダムに出現。  
3. **ゲームオーバー画面**  
   - 最終スコア、ハイスコア更新通知。  
   - 「リプレイ」ボタン。

- **パフォーマンステスト**

# 第1章　ゲームコンセプトと基本ルール  

## 1.1 ゲーム概要  
- **ジャンル**：タイムアタック型クリック（タップ）アクション  
- **基本プレイフロー**  
  1. タイトル画面 → モード選択（デモ 5 秒 / フル 60 秒）  
  2. ゲーム開始 → 動物がランダムに登場し、プレイヤーはクリック／タップで捕獲しようとする  
  3. 捕獲成功・失敗に応じてスコア・コンボが変動  
  4. 時間経過に応じて制限時間が段階的に延長され、最終的に最大 60 秒まで伸びる  
  5. 時間切れまたは 3 回連続で全動物を逃した時点でゲームオーバー → 結果画面へ遷移  

- **目的**：制限時間内にできるだけ高いスコアを獲得し、ハイスコアを更新すること。  

## 1.2 タイムアタック拡張ルール  
| ステージ | 制限時間（秒） | クリア条件（※） | 補足しません。|--------------|----------------|--------|
| ステージ 1（デモ） | 5 | **初回プレイ時のみ**表示。スコアに関わらず自動でステージ 2へ進行。 |
| ステージ 2 | 10 | **5匹以上の動物を捕獲** または **コンボ 2 回以上**を達成 |
| ステージ 3 | 20 | **10匹以上の動物を捕獲** または **コンボ 4 回以上** |
| ステージ 4 | 30 | **20匹以上の動物を捕獲** または **コンボ 6 回以上** |
| ステージ 5 | 45 | **35匹以上の動物を捕獲** または **コンボ 8 回以上** |
| ステージ 6（最終） | 60 | **50匹以上の動物を捕獲** または **コンボ 10 回以上**  ※最終ステージでは条件を達成しなくても時間切れまでプレイ可能。条件達成時に追加ボーナス（+10 % スコア）が発生。 |

> **※クリア条件の「または」は、いずれか一方を達成すれば次ステージへ進める。**  
> 条件未達成の場合は現在のステージ時間が終了した時点でゲームオーバーとなる。

### 1.2.1 時間延長のタイミング  
- 各ステージのクリア条件を満たした瞬間、**即座に次のステージの制限時間へ切り替える**。  
- 条件未達成の場合は残り時間が 0 になるまでプレイを続け、タイムアップでゲームオーバー。  

## 1.3 クリック捕獲メカニクス  
| 項目 | 内容 |
|------|------|
| **入力** | マウス左クリックまたはタッチスクリーンのシングルタップを「捕獲操作」とする。入力は `InputManager.TapEvent` ラッパーで統一し、PC・モバイル両対応。 |
| **ヒット判定** | 各動物プレハブに円形コライダー（半径 0.5 m）を付与。タップ座標がコライダー内に入ったら「捕獲成功」判定。 |
| **捕獲成功フィードバック** | 1. **画面フラッシュ**：白色のオーバーレイを 0.1 秒間表示（アルファ 0.3 → 0）。<br>2. **スコア加算アニメーション**：スコア数値が "+X" の形でポップアップし、上方向に 0.5 秒かけてフェードアウト。<br>3. **SE**：捕獲音（短い「ピッ」）を再生。 |
| **捕獲失敗（逃走）** | 動物が画面外へ一定速度で移動し続け、境界を超えた時点で「逃走」判定。逃走時に赤色フラッシュ（0.08 秒）と「逃げ音」を再生。 |

## 1.4 逃走コンボ倍率  
- **基本ルール**  
  - プレイヤーが動物を逃すと **逃走カウント** が 1 増加。  
  - 逃走カウントに応じた **コンボ倍率** は以下の通り：  

| 逃走回数 | コンボ倍率 |
|----------|------------|
| 0 (直前捕獲成功) | 1.0× |
| 1 | 1.5× |
| 2 | 2.0× |
| 3 | 2.5× |
| 4 | 3.0× |
| 5 | 3.5× |
| 6 以降 | 0.5× 増加ごとに **5.0×** を上限とする（例：7 回逃走 → 4.0×、9 回逃走 → 5.0×） |
| **捕獲成功時** | 逃走カウントを **0** にリセットし、コンボ倍率を 1.0× に戻す。 |

- **表示**：画面左上に「コンボ：×X.Y」形式でリアルタイム更新。逃走時に赤点滅、捕獲時に緑点滅でフィードバック。  

## 1.5 スコア計算式  
```
スコア増加量 = 基本ポイント × レア度係数 × コンボ倍率
```
- **基本ポイント**  
  - 通常動物：10 ポイント  
  - レア動物：30 ポイント（基礎値は同じだがレア度係数で調整）  
- **レア度係数**  
  - 通常動物：1.0  
  - レア動物：2.0（出現確率 1 % のレア動物は得点が 2 倍）  
- **コンボ倍率**：上記セクション 1.4 の表を参照。  

**例）**：  
- 通常動物を捕獲し、現在の逃走回数が 2（コンボ倍率 2.0×） → 10 × 1.0 × 2.0 = **20 ポイント**  
- レア動物を捕獲し、逃走回数が 0（コンボ倍率 1.0×） → 10 × 2.0 × 1.0 = **20 ポイント**  
- レア動物を捕獲し、逃走回数が 4（コンボ倍率 3.0×） → 10 × 2.0 × 3.0 = **60 ポイント**  

得点は整数に丸め（小数点以下切り捨て）て UI に表示する。  

## 1.6 レア動物出現確率 1 % & スケーリング速度増加  
| 項目 | 詳細 |
|------|------|
| **出現確率** | 動物スポーン時に 0‑99 の整数乱数を生成。0 が出たら **レア動物**、それ以外は **通常動物**。したがってレア出現率 = 1/100 = 1 %。 |
| **レア捕獲時のスピードブースト** | レア動物を捕獲するたびに、現在のゲームスピード係数に **0.10（10 %）** を加算。上限は **3.00（300 %）** まで。<br>例：初期速度 1.0 → 1回目レア捕獲後 1.10 → 2回目 1.20 … 20回目で 3.00 に到達。 |
| **スピード適用対象** | 全動物の移動速度、出現間隔（スポーン間隔）、および逃走速度に同じ係数を掛ける。これにより難易度が徐々に上がる。 |
| **速度リセット条件** | ゲームオーバー時またはプレイヤーが手動でリトライしたときに速度係数を 1.0 に戻す。 |

## 1.7 ゲームオーバー条件  
1. **タイムアタック終了**  
   - 現在のステージ制限時間が 0 になった瞬間。  
   - 最終スコアはその時点の累計得点とし、ハイスコアと比較して更新チェックを行う。  

2. **連続逃走罰則**  
   - プレイヤーが **3 回連続で全ての出現動物を逃した** 場合、即座にゲームオーバー。  
   - 「連続逃走」とは、動物が画面外に逃げてから次に新しい動物が出現するまでの間に、プレイヤーが一度も捕獲に成功していない状態を指す。  
   - この条件は、タイムアップとは別に判定され、いずれかが先に満たされたらゲーム終了。  

**ゲームオーバー処理フロー**  
1. ゲームオーバーフラグを立てる。  
2. 動物のスポーンを停止し、残っている動物はフェードアウトさせる。  
3. 最終スコアを表示し、`HighScoreManager` に保存要求を発行。  
4. 「リプレイ」ボタンと「タイトルへ戻る」ボタンを表示。

### 本章のまとめ  
- プレイヤーは短いデモタイムから始め、設定された捕獲・コンボ条件を達成することで制限時間を段階的に伸ばし、最終的に最大 60 秒までプレイできる。  
- クリック捕獲はシンプルだが、逃走コンボ倍率とレア動物によるスピードブーストという二層のリスク・リワード要素が戦略性を生む。  
- スコア計算はベースポイント・レア度・コンボ倍率の乗算で明確かつ拡張しやすい。  
- レア出現確率 1 % と捕獲ごとの速度上昇により、プレイは徐々に難しくなり、ハイスコア競争を促進。  
- ゲームオーバーは時間切れまたは連続逃走 3 回という二つの条件で判定し、その結果に基づいてハイスコアをローカルストレージに保存する。
